# 家庭仓库管理（Home Warehouse）

纯前端的 3D 家庭仓库管理工具：用立方体管理家里所有的物品和容器，支持分层收纳、临期提醒、存档导入导出。
无后端、无依赖安装，打开即用。

## 功能

- **3D 视图**：立方体表示容器 / 物品 / 实体（床、桌、墙等占位物），轨道相机（右键旋转、滚轮缩放），标签引出线标注每个物体
- **列表视图**：左侧结构树按层级展示，支持搜索（名称 / 标签 / 类型 / 所在容器路径，Enter 逐个定位）
- **拖拽摆放**：鼠标拖动移动物体，Shift+拖动（或「升降锁定」）上下移动；网格吸附、落地吸附、空腔自动归属
- **多空腔容器**：容器可设多个内腔，支持分割向导（垂直分层 / 水平格子 / 不等分占比），一键生成衣柜、鞋柜、抽屉结构
- **只操作模式**：按容器 / 物品 / 实体过滤可选中对象，互不干扰，方便分步骤搭建场景
- **提醒系统**：物品可设保质期（临期标红）与周期任务（换滤芯等），自动推进下一周期
- **撤销 / 重做**：30 步快照式撤销，操作历史面板可点击任意一步直接跳转
- **暂存区**：一键召回飞出场景的物体，可放回原位
- **单位切换**：mm / cm / m 显示切换，内部一律毫米整数存储
- **存档**：localStorage 自动保存；JSON 导出 / 导入（下载、复制粘贴双通道）
- **其他作品**：作者的其他小站

## 使用

### 本地打开

双击 `index.html` 即可（three.js 从 CDN 加载，需联网）。

## 快捷键

| 按键 | 功能 |
|---|---|
| 左键拖动 | 水平移动物体 |
| Shift + 拖动 | 上下移动物体（或开启「升降锁定」） |
| 右键拖动 / 滚轮 | 旋转 / 缩放视角 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| F | 相机定位到选中物体 |
| / | 聚焦搜索框 |
| Esc | 取消选中并释放键盘焦点 |
| Delete | 删除选中物体 |

## 存档格式

存档为 JSON，带 `schemaVersion` 字段保证向后兼容。单位为毫米整数，物体世界坐标由父链逐层累加，不做物理模拟（允许重叠，只做吸附对齐）。

## 技术栈

Vite 无需构建的单文件实现：原生 ES Module + [three.js](https://threejs.org) r169（CDN，importmap 映射）+ CSS2DRenderer 标签系统。所有几何与吸附逻辑为纯函数，避免乱飞。
